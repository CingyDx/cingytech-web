# Cingy.Tech — creative engineering prototype

## Intent
Build a separate, functional creative-development demonstration for Czech businesses buying websites, web applications and automation. Originality must help visitors understand the offer and reach contact. Preview approval precedes any production release. No award, income, AI integration or raytracing claims without evidence.

## Audit
- Existing static HTML/CSS/JS site, Netlify publish=public, zero package dependencies, main 0a563f1. Existing 15 tests pass.
- Genuine Blender Cycles source and VP9 loop already exist. Current production language is repeated purple glass panels and a video orb, not an interactive creative system.
- Local first-view transferred resources: desktop 7,571,089 bytes, mobile 5,189,267 bytes; video playing on both; no overflow at 1440/390. These are local checks, not field Core Web Vitals.
- Existing contact form and consent-based Ads tracking must remain unchanged. Contact CTA already says Kontakt. Hardware stays on ordinary website, not the experimental digital offering.
- Existing proof distinguishes Baník club website from DomFINS/WENSPOL nonbinding concepts. Preserve that distinction and exact links. Preserve three live template demos.

## Three directions and selection
1. Signal Loom: metallic violet filaments form a live spatial sculpture; service choices morph its structure. Open editorial typography, real data-cleaning experiment. Originality 5/5, business clarity 5/5, delivery risk 3/5.
2. Ink / Code: true-white editorial canvas, liquid ink simulation, code-shaped typography. Originality 4/5, clarity 4/5, risk 3/5; greater break from established identity.
3. Impossible Machine: cinematic exploded procedural machine assembling digital modules. Originality 5/5, clarity 3/5, risk 5/5; more assets and narrative time before contact.
Select Signal Loom for recognizable proprietary form and immediate service meaning. Scores are design judgments, not measured user research.

## Engineering
Create public/experiments/signal-loom/ only; no root-route, Ads, SEO, contact handler or production changes. Three.js pinned 0.186.1 bundled locally with MIT license. Custom GLSL vertex geometry deforms parallel ribbons into three modes, analytic environment reflections in fragment shader; no raytracing claim. Adaptive resolution, render pause when hidden/offscreen, context-loss fallback, reduced-motion static image, keyboard controls. Automatic motion on ordinary first open, no activation gate. Reduced-motion remains respected unless visitor manually requests motion.

Local CSV demo: semicolon-separated jmeno/email/stav, quoted-cell parsing, trim and lowercase email, dedupe by email, reject invalid emails, return counts and downloadable safe CSV. Local data never sent. Max 10,000 characters and 200 data rows. No backend/AI promises. Download neutralizes spreadsheet formula prefixes. Rendering uses textContent.

Contact: reuse existing poptavka markup and home.js submission logic on preview, existing consent script. No fabricated successful submissions. Tests mock POST and prevent any Google requests. No test lead sent to real backend.
